Connexion à GitHub

Pour publier directement sur ton site, il faut un jeton d'accès GitHub (une seule fois, il reste enregistré dans ce navigateur).

  1. Va sur github.com puis clique sur ta photo de profil > Settings > tout en bas à gauche : Developer settings > Personal access tokens > Fine-grained tokens > Generate new token
  2. Dans "Repository access", choisis "Only select repositories" et sélectionne natxmans/Zaleoo-carine
  3. Dans "Permissions" > "Repository permissions", trouve Contents et mets-le sur Read and write (c'est l'étape qu'on oublie souvent, et qui cause l'erreur "403 Resource not accessible")
  4. Génère le jeton, copie-le (il commence par github_pat_) et colle-le ci-dessous
